# Telco Customer Churn Prediction

---

### Project Overview
Customer churn is a critical problem in the telecom industry as losing customers directly impacts revenue. This project analyzes customer data to identify patterns that lead to attrition and uses data visualization to provide actionable business insights for improving retention.

---

### Objectives
* Perform data cleaning and preprocessing on raw customer datasets.
* Conduct exploratory data analysis (EDA) to find churn drivers.
* Build a classification model to predict the likelihood of customer departure.
* Create visual dashboards to help business decision-making.

---

### Tools & Technologies Used
* **Python**: For data manipulation (Pandas, Numpy).
* **Data Visualization**: Matplotlib, Seaborn, and Power BI.
* **Machine Learning**: Scikit-learn for building predictive models.
* **Jupyter Notebook**: For documenting the analysis process.

---

### Key Insights
* **Contract Impact**: Customers on month-to-month contracts represent the highest churn risk.
* **Service Quality**: Specific internet service types (Fiber Optic) show a correlation with higher churn rates.
* **Retention Strategy**: Improving the experience of new customers (first 6 months) is vital for long-term growth.
